# FX Checker 💱

A modern foreign exchange checker built with React, designed to provide real-time currency conversion, historical exchange rates, and multi-currency comparison.

## ✨ Overview

FX Checker is a responsive foreign exchange application that allows users to convert currencies, check live exchange rates, explore historical data, compare multiple currencies, and save frequently used currencies.

The project focuses on building a clean financial dashboard with reusable React components and custom hooks.

## 🚀 Features

* 💱 Real-time currency conversion
* 🔄 Currency swap
* 🔎 Searchable currency dropdown
* ⭐ Favorite currencies
* 📊 Historical exchange-rate charts
* 📈 Multi-currency comparison
* 🕘 Exchange-rate history
* 💾 Persistent data with Local Storage
* 📱 Responsive design
* ⚡ Loading and error states
* 🎯 Reusable custom React hooks

## 🛠️ Tech Stack

* React
* JavaScript
* Vite
* Recharts
* Tailwind CSS
* Frankfurter API
* Git & GitHub

## 🌐 API

Exchange-rate data is provided by the Frankfurter API.

It provides exchange-rate data based on European Central Bank reference rates.

## ⚙️ Getting Started

Clone the repository:

```bash
git clone https://github.com/abdulJalilHabibi/FX-Checker.git
```

Go to the project directory:

```bash
cd FX-Checker
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Then open the local development URL shown in your terminal.
